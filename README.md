# NetworkMonitor

Network monitoring project for a home lab.

## Features

- ARP network discovery
- Device inventory
- Custom device names
- Online/offline detection
- Telegram notifications
- Multiple network support

## Hardware

Initial deployment:

- ECS BAT-MINI
- Intel Celeron N2807
- 2 GB RAM
- Ubuntu 16.04 LTS
- Ethernet interface: enp3s0

## Network

Initial monitored network:

- Network: 192.168.0.0/24
- Monitor: 192.168.0.216
